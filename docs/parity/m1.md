## Package A — pipeline core
Owns: `lib/jobs/processor.ts`, `lib/jobs/queue.ts`, `worker/index.ts`, `lib/jobs/scheduler-config.ts`, `lib/ai/providers.ts`, `lib/meetings/repository.ts`, `lib/meetings/postgres-repository.ts`, new `lib/meetings/action-item-merge.ts`, `db/migrations/015_*`, `db/schema.sql`, `.env.example`; tests `job-processor`, `job-queue`, `action-item-merge`, `postgres-intelligence-tx` (new), `meeting-repository` (edit).
- **A1 assetId**: `selectMediaAsset(meeting, payload)`: `payload.assetId` (missing → `UnrecoverableError`) → `payload.storageKey` → newest asset with storageKey. Pass providers `{...meeting, mediaAssets:[selected, ...others]}`. `providers.ts:951` Gemini uses `find(a => a.storageKey)`. Record `inputAsset` in ai_runs metadata.
- **A2 platform recordings**: no asset + `payload.platform` zoom|teams + `payload.captureEvent` → stage `recording.download`, `importPlatformRecording(...)`, re-fetch, select by returned assetId. Else "no recording attached" as `UnrecoverableError`.
- **A3 permanent vs retryable**: export `processJob`. `toPermanentError` wraps missing meetingId, meeting not found, no/unknown asset, `TranscriptionUnavailableError`. In catch: `maxAttempts = job.opts.attempts ?? 1`; `isFinal = UnrecoverableError || job.attemptsMade + 1 >= maxAttempts`. Not final → job `queued` with error + attempts, no meeting status change, no event, rethrow. Final → failJob, meeting `failed`, exactly one `meeting.process_failed` (payload += attempts, permanent). Side-effect calls `.catch(() => {})`.
- **A4 ai_runs**: `SummaryProvider` gains `id`, `model`, `getLastRun?()`. Gemini: model = `GOOGLE_GEMINI_SUMMARY_MODEL ?? "gemini-3.5-flash"`; fallback paths set `{provider:"heuristic", model:"heuristic-v1", fallbackUsed, fallbackReason}`. Replace all `GOOGLE_GEMINI_SUMMARY_MODEL ?? "heuristic-v1"` (processor ~170,188,253,272). On transcription/summary error record `status:"failed"` ai_run (guarded) then rethrow. Write `job_id`.
- **A5**: `meeting.transcribe` → processMediaJob; `meeting.index` → `processIndexJob` (no transcription; returns `{indexed:false, reason:"search indexing ships in M6"}`; UnrecoverableError if no transcript). Keep stage label `meeting.index`.
- **A6 dispatch**: `webhook.deliver` handled before markActive, no jobs-row bookkeeping: `deliveryId` → `processWebhookDeliveryJob({deliveryId, attempt: attemptsMade+1, maxAttempts})`; legacy `{eventName,data}` → `deliverWebhookEvent`. `teams.subscription.renew` → `renewTeamsSubscriptions()`. `action_item.created` only for ids not present before.
- **A7 queue**: `attempts = MEETSUM_JOB_ATTEMPTS ?? 3`, backoff exp 3000; persist `maxAttempts` into `jobs.max_attempts`.
- **A8 worker**: if `isTeamsSubscriptionConfigured()` enqueue renew at startup + every `MEETSUM_TEAMS_SUBSCRIPTION_RENEW_MINUTES` (360); config getter `getCaptureScheduleConfig(env)` in scheduler-config.ts.
- **A9 transactional upsert preserving edits**: generic `withTransaction<T>`. Whole upsert in one tx. Pure `lib/meetings/action-item-merge.ts`: `normalizeTaskTitle` (NFKC, lowercase, strip niqqud `[֑-ׇ]`, `[^\p{L}\p{N}]+`→space, trim); `mergeActionItems(existing, incoming, createId) → {keep, update, insert, remove}`. Protected = `editedByUser || origin==="user" || status==="done"` (kept, never modified; matching incoming dropped). Match on `normalizeTaskTitle(originalTitle ?? title)`. Unprotected match → update in place (same id). Unmatched unprotected → remove. Unmatched incoming → insert (regen id on collision). SQL: select ... for update, delete any($2), updates, inserts with `origin='ai', original_title=title, edited_by_user=false`. Return final persisted list. `updateActionItem`: `edited_by_user = true` when title/owner/dueDate/priority patched; `completed_at` on done/open. Map new columns. Mirror in in-memory repo.
- **A10**: scoped `findMediaAssetBySourceFile` (`and meeting_id = $3` when given; unscoped kept for Drive). `createMeeting` persists external_*. `createMeetingIfAbsent` via `on conflict ... do nothing returning`, else select existing. `findMeetingByExternalId`. `discardMeeting` in tx guarded by not-exists transcript/summaries.
- **Tests**: job-processor (assetId selection; unknown asset permanent; transient attempt 1/3 not failed; 3/3 failed with one event; TranscriptionUnavailable permanent; failed ai_run row; summary model from getLastRun; action_item.created only new; zoom payload → importPlatformRecording; webhook.deliver → processWebhookDeliveryJob without updateJob; meeting.index never transcribes). job-queue (attempts from env, jobId, maxAttempts). action-item-merge (rename survives, done kept, update in place, stale removed, niqqud match, id collision). postgres-intelligence-tx (begin/commit, rollback on mid-failure; updateActionItem sets edited_by_user). meeting-repository (preserve on reprocess, createMeetingIfAbsent idempotent, scoped lookup, discardMeeting refuses with transcript).

Owns: `lib/capture/*` (desktop-upload, desktop-ingestion, zoom, teams, types, registry, new multipart-upload, media-validation, recording-import, teams-subscriptions), `lib/storage/object-storage.ts`, `app/api/meetings/[id]/upload/route.ts`, `app/api/desktop-capture/ingest/route.ts`, `app/api/webhooks/zoom/route.ts`, `app/api/webhooks/teams/route.ts`, new `app/api/webhooks/teams/lifecycle/route.ts`, new `app/api/integrations/teams/subscription/route.ts`, `components/command-center-shell.tsx` (only `importDesktopFile`), `package.json`/lock, `db/migrations/016_*`; tests desktop-capture-route, desktop-capture-ingestion, zoom-capture, teams-capture, capture-adapter (edit) + new multipart-upload, media-validation, recording-import, teams-subscriptions, capture-webhook-routes.

## Package C — webhooks, SSRF, rate limiting, Hebrew regex

- **C1 SSRF** `url-guard.ts`: `isBlockedAddress` (net.BlockList: 0/8,10/8,100.64/10,127/8,169.254/16,172.16/12,192.0.0/24,192.0.2/24,192.168/16,198.18/15,198.51.100/24,203.0.113/24,224/4,240/4; ::,::1,fc00::/7,fe80::/10,ff00::/8,2001:db8::/32; mapped/NAT64 IPv4). `assertSafeWebhookUrl`: https (http only allowlisted or non-prod), no credentials, reject localhost/.local/.internal/.home.arpa, resolve all addresses and reject any blocked; `MEETSUM_WEBHOOK_ALLOWED_HOSTS` (hosts, *.suffix, CIDR) bypass. `guardedWebhookFetch` with undici Agent custom connect lookup (rebinding defence), `redirect:"manual"`, timeout, drain body.
- **C2 per-subscription secrets**: create validates URL, secret given (≥16) or generated `whsec_…`, store `secret_ciphertext` via `lib/auth/secret-crypto.ts`, return secret once. Update supports url/enabled/events/rotateSecret. `deleteWebhookSubscription` + DELETE route. `resolveSubscriptionSecret` falls back to global for legacy. Test signature + test send use subscription secret and guarded fetch. Retry resets to queued and enqueues. UI: show one-time secret with copy, rotate, delete, queued/retrying statuses.
- **C3 BullMQ delivery**: `deliverWebhookEvent` inserts queued rows per subscription (`max_attempts = MEETSUM_WEBHOOK_MAX_ATTEMPTS ?? 6`) and enqueues `webhook.deliver {deliveryId}` directly on the queue (jobId=deliveryId, exponential backoff `MEETSUM_WEBHOOK_BACKOFF_MS ?? 30000`); enqueue failure → one inline attempt. `processWebhookDeliveryJob`: missing/disabled → cancelled; headers content-type, x-meetsum-signature, x-meetsum-event, x-meetsum-delivery; 2xx sent; unsafe URL or 4xx (≠408/429) → failed + `UnrecoverableError`; else retrying/failed + throw.

- **C5 Hebrew regex**: `termRegex` with `(?<![\p{L}\p{M}\p{N}])` / `(?![\p{L}\p{M}\p{N}])` + `u` flag and optional Hebrew prefix group; replacements keep prefix with maqaf (`ב-Supabase`); Gemma/MCP strict, no prefix (so `דוגמה`, `מגמה`, `דוגמא` untouched). Fillers non-global; drop segment only if <2 letter-words remain after stripping fillers. Dedupe only immediately previous kept segment, same speaker, gap ≤2000 ms. Word-bounded auto-tags (`stops` ≠ ops, `rapid` ≠ api). Non-global regexes for `.test`.
- **Tests** as listed (url-guard matrix incl. no redirect follow; delivery fan-out/sign/retry/fail/cancel/inline; management secret once/private rejected/rotate/delete; rate-limit hops/header/invalid/spoof; Hebrew cleanup cases; existing language-intelligence still passes).
