# M4 — Player & transcript UX: implementation spec

Base `parity/m4-player`, stacked on `parity/m3-asr` (assumes M2+M3 integrated: `withAuthz`, `ctx.meetings`, `canManageMeeting`, `getShareLookup()`, speakers with `talk_time_ms`, `transcript_segments.words/turn_index/source`, `transcript-words.ts`, speaker mapping panel). Migrations 015–020 exist; adds **021**. Packages: A media backend, B transcript/meeting data + APIs, C client UI — disjoint ownership. Orchestrator commits Step 0 first.

## Design system (Cadence v2.0) — applies to all Package C UI
M4 is built on M3.5 (tokens + primitives in `components/ui`, meeting atoms, `lib/motion.ts`). Follow `design-system/README.md` §7–10 and the showcase (`node design-system/showcase/build.mjs --preview`). Surfaces owned here: player with speaker timeline, compact player, source trace, transcript follow, citation peek.
- **Text direction (overrides any `dir` rule below):** paragraph `dir` comes from the segment's ASR language (`he` → rtl, `en` → ltr); for `mixed`/unknown segments use the **meeting's primary language**, never `dir="auto"` (a code-switched Hebrew line often starts with a Latin word and `auto` would render it LTR). Word-level language from M3 only drives `<bdi>` around English runs. `dir="auto"` is reserved for text with no known language (user input, search box, edited field while typing).
- Hebrew strings: RLM after a Latin word preceding digits; word-joiner after prefix hyphens (ל-, ה-).
- Never mirror player, scrubber, speaker timeline, chapter ticks, waveform in RTL. Mono timecodes LTR-isolated. Hebrew face via `[lang="he"]`.
- `--ai` (iris) only for model-written content; `--live` only for recording. One primary action per view — in the meeting view that's Play.
- No citation, no claim: render a `TimecodeChip`/`CitationChip` only when it resolves to a real segment.
- Status pills only for exceptions (live, processing, new, review, failed) — never "Ready".
- Request a design review from the "Meetsum design system" session before opening the PR (he/en × light/dark).

## Findings
- List payload heavy: `listMeetingsPage` hydrates each meeting (~10 queries) incl. full transcript. Inbox only needs `id, title, source, status, startedAt, tags, participants(.length), participantDetails.length, mediaAssets.some`.
- Shell polls providers/workspace/jobs every 8 s regardless of activity/visibility.
- No player or media route; `MediaAsset` has no duration column (only desktop sets `metadata.durationMs`).
- `selectMediaAsset` picks newest asset → playback renditions must be filtered by kind.
- Missing `on delete cascade` FKs to meetings: media_assets, speakers, transcript_segments, summaries, action_items, ai_runs, agent_runs; summary_sections→summaries.
- Seek sources exist: `ActionItem.sourceStartMs`, `timestampedQuotes[].startMs`, `MeetingAnswer.citations[{segmentId,startMs}]` (shell discards citations today).
- Share sections `summary|decisions|action_items|transcript|participants`, unvalidated.
- Vitest is node-only, `tests/**/*.test.ts`, no jsdom → no component tests; logic in pure `lib/` modules.
- Dockerfile has ffmpeg; M3 `lib/ai/asr/audio.ts` has `probeDurationMs` + injectable execFile.
- shadcn alert-dialog, dialog, dropdown-menu, popover, slider, tooltip, kbd available.
- MCP `get_transcript_segments` reads `meeting.transcript` from `GET /api/meetings/[id]` → compat needed.

## Decisions (normative)
- **Media proxied, never presigned to browser.** Node route streams S3 GetObject with Range.
- **Playback asset** (pure `selectPlaybackAsset(assets, variant)`): `audio` (default) → newest `kind='playback'`, else newest original browser-playable audio (`audio/mpeg|mp4|x-m4a|aac|webm|ogg|wav|x-wav|flac`), else original `video/mp4|webm`, else none. `video` → newest original with `retention='video'` and `video/mp4|webm`, else 404. Video only when user opens video panel.
- **Playback rendition**: worker job `media.prepare` → AAC-LC mono `.m4a` at `MEETSUM_PLAYBACK_AUDIO_BITRATE=64k`, `-movflags +faststart` (~29 MB/h); stored as `media_assets` row `kind='playback'`, `derived_from_asset_id`. `MEETSUM_PLAYBACK_TRANSCODE=auto` skips when original is `audio/mpeg|mp4|x-m4a|aac` ≤ `MEETSUM_PLAYBACK_PASSTHROUGH_MAX_BYTES` (100 MiB); `always|never`.
- **Peaks**: `ffmpeg -i src -ac 1 -ar 8000 -f s16le pipe:1` → `PeaksAccumulator`; `samplesPerPeak = max(400, ceil(totalSamples / MEETSUM_PEAKS_MAX_POINTS=20000))`; bucket abs max scaled 0..255; JSON `{v:1, durationMs, sampleRate, samplesPerPeak, max, peaks}` at `<original-key-dir>/derived/<assetId>.peaks.v1.json`, key in `media_assets.peaks_storage_key` on the original. Client max-pools to pixel width, gamma 0.6; flat bar fallback.
- **Duration**: ffprobe → `media_assets.duration_ms` at prepare (fallback PCM sample count). Denormalized `meetings.duration_ms` (media, else max(end_ms)). `getMeetingDurationMs` checks `meeting.durationMs` first.
- **Virtualizer `@tanstack/react-virtual`** (headless ~5 KB vs virtuoso ~16–18 KB; `measureElement`, `scrollToIndex({align:"center"})`; custom follow logic anyway). `useFlushSync:false` (React 19). Budget: `/[locale]` First Load JS delta ≤ +15 KB, recorded in PR.
- **Time axis always LTR** in RTL (scrubber/waveform/speaker bar never mirrored; transport cluster `dir="ltr"`, localized labels). → and `l` always forward; pure keyboard map takes `dir` with tests showing no inversion. Shortcuts use `event.code` (work under Hebrew layout).
- **One player store per selected meeting**: external store via `useSyncExternalStore` (no dep), rAF while playing, derives `activeSegmentIndex`/`activeWordIndex` by binary search, emits only on change; `currentMs` throttled 15 Hz; rows subscribe with a selector so ~2 rows re-render per tick.
- **Editing preserves timings** via LCS anchor alignment; edited segments `source='edited'`, `revision++`, row in revisions table; undo pops latest. Full re-ASR discards edits (UI confirms if `editedSegmentCount > 0`); `transcript-cleanup` reprocess keeps edits (`replaceTranscript(..., {preserveEdited:true})`).
- **Permissions**: `meeting:read` media/peaks/transcript; `meeting:write` segment edit/undo/rename; `meeting:read` + `canManageMeeting` DELETE (owner/admin; API key needs admin). Flag: rename is `meeting:write`.
- **Share media opt-in**: new section `media` not in default `includedSections`; share dialog "Include recording".

```sql
alter table media_assets
  add column if not exists kind text not null default 'original',
  add column if not exists derived_from_asset_id text references media_assets(id) on delete cascade,
  add column if not exists duration_ms integer,
  add column if not exists peaks_storage_key text,
  add column if not exists prepared_at timestamptz,
  add column if not exists prepare_error text;
do $$ begin
  if not exists (select 1 from pg_constraint where conname = 'media_assets_kind_check') then
    alter table media_assets add constraint media_assets_kind_check check (kind in ('original','playback'));
  end if;
end $$;
create index if not exists idx_media_assets_meeting_kind on media_assets(meeting_id, kind, created_at desc);
update media_assets set duration_ms = round((metadata->>'durationMs')::numeric)::int
  where duration_ms is null and (metadata->>'durationMs') ~ '^[0-9.]+$';
update media_assets set duration_ms = round((metadata->>'durationSeconds')::numeric * 1000)::int
  where duration_ms is null and (metadata->>'durationSeconds') ~ '^[0-9.]+$';

alter table meetings
  add column if not exists duration_ms integer,
  add column if not exists transcript_version integer not null default 0;
update meetings m set duration_ms = coalesce(
  (select max(a.duration_ms) from media_assets a where a.meeting_id = m.id),
  (select max(s.end_ms) from transcript_segments s where s.meeting_id = m.id))
  where m.duration_ms is null;

alter table transcript_segments
  add column if not exists revision integer not null default 0,
  add column if not exists edited_at timestamptz,
  add column if not exists edited_by_user_id text references users(id) on delete set null;

create table if not exists transcript_segment_revisions (
  id text primary key,
  workspace_id text not null references workspaces(id) on delete cascade,
  meeting_id text not null references meetings(id) on delete cascade,
  segment_id text not null references transcript_segments(id) on delete cascade,
  revision integer not null,
  text text not null,
  words jsonb,
  speaker_id text,
  source text not null,
  created_by_user_id text references users(id) on delete set null,
  created_at timestamptz not null default now(),
  reverted_at timestamptz
);
create index if not exists idx_segment_revisions_segment on transcript_segment_revisions(segment_id, revision desc);

do $$ declare r record; begin
  for r in
    select c.conname, c.conrelid::regclass::text as tbl, a.attname as col
    from pg_constraint c join pg_attribute a on a.attrelid = c.conrelid and a.attnum = any(c.conkey)
    where c.contype = 'f' and c.confrelid = 'meetings'::regclass and c.confdeltype = 'a'
      and c.conrelid::regclass::text in ('media_assets','speakers','transcript_segments','summaries','action_items','ai_runs','agent_runs')
  loop
    execute format('alter table %s drop constraint %I', r.tbl, r.conname);
    execute format('alter table %s add constraint %I foreign key (%I) references meetings(id) on delete %s',
      r.tbl, r.conname, r.col, case when r.tbl = 'ai_runs' then 'set null' else 'cascade' end);
  end loop;
  for r in
    select c.conname from pg_constraint c
    where c.contype = 'f' and c.conrelid = 'summary_sections'::regclass
      and c.confrelid = 'summaries'::regclass and c.confdeltype = 'a'
  loop
    execute format('alter table summary_sections drop constraint %I', r.conname);
    execute format('alter table summary_sections add constraint %I foreign key (summary_id) references summaries(id) on delete cascade', r.conname);
  end loop;
end $$;
```

## Package A — media backend
Owns: `lib/media/**` (range, conditional, proxy, playback-select, peaks, peaks-accumulator, prepare, ffmpeg), `lib/storage/object-storage.ts`, `lib/storage/media-assets.ts`, `lib/storage/retention.ts`, `lib/jobs/processor.ts`, `lib/jobs/queue.ts`, `worker/index.ts`, `lib/sharing/share-media-access.ts`, routes `app/api/meetings/[id]/media/route.ts`, `.../media/peaks/route.ts`, `app/api/share/[token]/media/route.ts`, `.../media/peaks/route.ts`, `scripts/media-prepare-backfill.ts`.
- A1 `range.ts` pure: `parseRange(header, size, {maxChunkBytes = MEETSUM_MEDIA_MAX_RANGE_BYTES=8388608})` → full | partial{start,end} | unsatisfiable. `bytes=a-b`, `a-`, `-n`; clamp end to size-1 and start+max-1; start≥size or suffix 0 → unsatisfiable; malformed/non-bytes/multi-range → full; size 0 → full.
- A2 `conditional.ts` pure: `evaluateConditionals(...)` → not_modified | ignore_range | proceed. If-None-Match weak + `*` for GET/HEAD → 304; If-Range strong ETag or date, mismatch → full 200. ETag `"a-<assetId>-<checksum8|createdAtEpoch>"`, Last-Modified = asset createdAt.
- A3 storage: `getMeetingObjectRange(key, {start?, end?, signal?})` (GetObject Range, `transformToWebStream()`, abortSignal), `headMeetingObject`, `storeMeetingObjectFile`, `putMeetingObjectJson`, real `deleteMeetingObjects` (DeleteObjects batches of 1000; NoSuchKey = deleted).
- A4 `proxy.ts` `createMediaResponse({request, asset, deps})`: HEAD, 304, 416 (`bytes */size`), 206 (`Content-Range`, `Content-Length`), 200. Always `Accept-Ranges: bytes`, Content-Type, ETag, Last-Modified, `Cache-Control: private, max-age=${MEETSUM_MEDIA_CACHE_MAX_AGE_SECONDS=3600}`, `Content-Disposition: inline`, `X-Content-Type-Options: nosniff`. request.signal abort → abort S3 + cancel stream. NoSuchKey → 404 `media_missing`; InvalidRange → 416; else 502 `media_unavailable`.
- A5 routes (`runtime="nodejs"`, `dynamic="force-dynamic"`): `GET|HEAD /api/meetings/[id]/media?variant=audio|video` (`meeting:read`; invisible 404; no asset 404 `no_media`; bad variant 400; not audited/rate-limited). `GET .../media/peaks` (ETag `"p-<assetId>-<preparedAtEpoch>"`, 304, 404 `no_peaks`).
- A6 share routes `withPublicRoute("share media")`; `authorizeShareMediaRequest` → 404 on any failure: active share (not revoked/expired, visibility link), workspace `publicSharingEnabled`, `includedSections` has `media`, password → `verifyShareAccessCookie`.
- A7 `prepareMediaAsset({meetingId, assetId, repo, env, exec?, storage?})`: skip if prepared + playback exists (unless force); download to temp; probe duration; peaks pass → put JSON; transcode per policy → upload → `createMediaAsset({kind:"playback", derivedFromAssetId, retention:"audio", durationMs, contentType:"audio/mp4"})` replacing older playback; `updateMediaAssetPreparation`; `setMeetingDurationMs(…,"media")`; always clean temp. `MEETSUM_MEDIA_PREPARE_TIMEOUT_MS=900000`; `FFMPEG_PATH`/`FFPROBE_PATH`.
- A8 processor/queue: asset selection ignores `kind!=='original'`; processMediaJob enqueues `media.prepare {meetingId, workspaceId, assetId}` (jobId `media.prepare:<assetId>`) unless `MEETSUM_MEDIA_PREPARE=false`; 2 attempts, final failure stores `prepare_error` + audit; not a processing job (never fails meeting). transcript-cleanup uses `preserveEdited:true`. `storage.delete {workspaceId, keys}` 5 attempts exp backoff. Missing meeting → UnrecoverableError.
- A9 storage/retention also delete derived rows' objects + peaks objects; admin list shows kind.
- A10 backfill script (dry-run unless `--execute`; `--limit`, `--meeting`).
- Tests: media-range, media-conditional, media-route (mocked storage + ctx: exact 206 headers, 200, HEAD no body, 416, 304, If-Range mismatch 200, variant, no_media, invisible 404, NoSuchKey 404, other 502, abort propagates, private cache), share-media-route, playback-select, media-peaks (odd byte boundaries, cap, downsample, parse rejection), media-prepare (injected exec/storage, ffprobe parse, mp3 passthrough, playback row, idempotent, prepare_error, temp cleanup), storage-delete-job; edits job-processor, media-retention.
