# M9: i18n/RTL and product polish, implementation spec

**Base branch:** `parity/m9-polish`, stacked on the M8 branch. Migrations up to 025 are already there, so M9 adds **026** and nothing else.

**Shape:** Step 0 (orchestrator), then four parallel packages A–D with strictly disjoint file ownership, then an Integration step.

**Goal:** Hebrew quality that is clearly better than Fireflies, measured by the acceptance criteria at the end, plus the parity polish still open: analytics, notifications, onboarding, PWA, routing, dialogs and segment states.

**Design rules:** everything follows design-system README §7–10:
- set `dir` from the language you know;
- `<bdi>` around names, emails and product names;
- LTR-isolated mono timecodes;
- time axes never mirror;
- iris only on AI content;
- one primary action per view;
- status pills only for exceptions.

## Decisions (normative)
- **Locales: `he` (default) and `en` only.**
  - `LEGACY_LOCALES = ["pt","es","it"]`: proxy sends these URL prefixes 308 to the resolved locale and keeps the rest of the path. A legacy cookie is ignored.
  - `defaultLocale` values of pt/es/it in settings are coerced to `he` on read, and 026 rewrites them.
  - The `MEETSUM_DEFAULT_LOCALE` env var (default `he`) is the fallback.
- **Locale resolution, in order:** URL prefix → cookie `meetsum_locale` → Accept-Language (q-sorted; `he`, `he-IL` and `iw` map to `he`; `en-*` maps to `en`) → default.
  - Redirects carry `Vary: Accept-Language, Cookie`.
  - On login, the OAuth callback sets the cookie from `users.locale` when it is present.
  - Switching language persists `users.locale` when there is a session.
- **Time zone, in order:** `users.time_zone` → `workspace_settings.timeZone` → `MEETSUM_TIMEZONE` → `Asia/Jerusalem`. Values are validated with `Intl.supportedValuesOf("timeZone")`.
  - The server resolves it once per request and passes it to `I18nProvider`.
  - Every formatter requires an explicit `timeZone` (enforced by the type).
  - Relative times ("לפני 5 דקות") render the absolute value on the server and switch to relative after mount via `useNow()`, inside `<time dateTime>`, so hydration never mismatches.
- **One formatting module.** `lib/i18n/format.ts` is the only place allowed to call `Intl.DateTimeFormat`, `toLocale*String`, `Intl.NumberFormat` or `Intl.RelativeTimeFormat`. A new `check.mjs` rule, `locale-format`, enforces it.
  - Digits are always Western (`numberingSystem:"latn"`) with `calendar:"gregory"`, and `he` uses `hourCycle:"h23"`.
- **Hebrew typography is applied at render and export time, never persisted.** Stored text, search offsets (M4 `transcript-search` offset maps) and copy/clipboard always use raw text.
  - Transcript segment text is left untouched in the DOM.
  - The rules apply to summaries, titles, labels, dictionary strings, notifications, PDF, DOCX, email and Slack.
  - `lib/i18n/hebrew-text.ts` is canonical. M8's `lib/integrations/bidi.ts` re-exports its primitives.
- **PDF: pdfkit + bidi-js, with embedded IBM Plex Sans Hebrew, Plex Sans and Plex Mono.**
  - Why not `@react-pdf/renderer`:
    - it adds a React reconciler and yoga-wasm to a route handler;
    - it uses its own pdfkit fork anyway;
    - its line layout doesn't apply the full UAX #9 bidi algorithm to mixed-direction lines;
    - it gives no control over grapheme-safe reordering.
  - Why pdfkit:
    - fontkit does the shaping: GPOS mark positioning for niqqud, plus kerning;
    - fonts are subsetted with a ToUnicode CMap, so Hebrew stays copyable and searchable;
    - `lang` and tagged PDF are supported.
  - We wrap lines in **logical** order with an injected measurer, then reorder each line **visually** with bidi-js, reversing by grapheme cluster (`Intl.Segmenter`) so combining marks stay attached, and apply bracket mirroring.
  - Requires `serverExternalPackages: ["pdfkit"]` in `next.config.mjs` (pdfkit reads its AFM files via `__dirname`).
  - Fonts come from the npm packages `@ibm/plex-sans-hebrew`, `@ibm/plex-sans` and `@ibm/plex-mono` (OFL, TTF under `fonts/complete/ttf/`; Step 0 verifies the path and vendors the files into `assets/fonts/` with `OFL.txt` if it is wrong).
  - `MEETSUM_PDF_FONT_DIR` overrides the font location.
- **Filenames** use `lib/http/content-disposition.ts`: `attachment; filename="<ascii>"; filename*=UTF-8''<pct-encoded>`.
  - The UTF-8 name: NFC; bidi controls and C0/C1 control characters stripped; `<>:"/\|?*` and path separators replaced with `-`; whitespace collapsed; trailing dots and spaces trimmed; Windows reserved names (CON, NUL, COM1…) prefixed with `_`; capped at 120 code points without splitting a surrogate pair; extension appended after the cap.
  - The ASCII fallback is the transliteration-free `meetsum-<yyyy-mm-dd>-<id8>.<ext>`, used whenever the title has fewer than 3 ASCII letters.
  - If M8 inlined an equivalent helper, move it here and re-export it.
- **Shell URL is the single source of truth.** `?panel=<MainPanelKey>&meeting=<id>&tab=summary|transcript|ask&t=<sec>&adminTab=<…>` plus `#section`.
  - Default values are omitted from the URL.
  - Panel and meeting changes use `router.push` (they create history entries). Tab and `t` changes use `router.replace`.
  - State is derived from `useSearchParams()`; there is no mirrored `useState`.
  - The server page parses `searchParams` and renders the right panel and meeting on first paint, including meetings outside the first page; the `deepLinkedMeetingRef` hack is deleted.
  - Unknown parameters such as `integration_error` and `q` are preserved.
  - Separate routes stay separate: `/[locale]/tasks` (M5), `/[locale]/analytics`, `/[locale]/onboarding`, `/[locale]/rooms/[id]`.
- **Dialogs.**
  - `components/ui/confirm-dialog.tsx` (promoted from admin) and `components/ui/prompt-dialog.tsx` (`usePromptDialog()` → `Promise<string|null>`, with validation and an `aria-describedby` error), both built on the shadcn Dialog/AlertDialog.
  - New `check.mjs` rules: `window-dialog` (`window.prompt|confirm|alert`) and `hand-built-modal` (`fixed inset-0` outside `components/ui/**`).
- **Notifications are pull-based and rendered client-side from the dictionary by kind.** The server stores only ids and short snapshots.
  - Visibility is re-checked at read time: a meeting the user can no longer see gets its title blanked and its link removed.
  - No email digest (out of scope).
- **Analytics only aggregates meetings visible to the requester** (`meetingScopeSql`), so a private meeting never leaks into a total. The per-member talk-time breakdown is for owner/admin only; members see workspace totals and their own numbers.
- **Hebrew copy style** (`docs/i18n/hebrew-style.md`, also enforced by tests):
  - plural imperative (העלו, הזמינו), never a gendered singular;
  - notification sentences are built around the object, not a gendered actor verb ("אזכור חדש מ־<bdi>דנה</bdi>", not "דנה הזכירה");
  - ״ for gershayim and ׳ for geresh, never ASCII `"` or `'` between Hebrew letters;
  - "…" instead of `...`;
  - glossary: פגישה, תמליל, סיכום, משימה, חדר, סביבת עבודה, הקלטה, דובר/ת → "דובר".

## Hebrew typography (`lib/i18n/hebrew-text.ts`, A; Step 0 provides signatures and a minimal implementation)
```ts
export const RLM="\u200F", LRM="\u200E", WJ="\u2060", NBSP="\u00A0", LRI="\u2066", RLI="\u2067", FSI="\u2068", PDI="\u2069"
export function hasHebrew(s: string): boolean
export function firstStrongDirection(s: string): "rtl"|"ltr"|"neutral"
export function isRtlLanguage(lang?: string|null): boolean          // he, iw, he-*, yi, ar, fa
export function directionFor(lang?: string|null, text?: string): "rtl"|"ltr"   // known lang first, else first strong
export function fixHebrewTypography(s: string, opts?: { base?: "rtl"|"ltr" }): string  // idempotent; no-op without Hebrew
export function isolateLtr(s: string): string                       // LRI…PDI, plain-text outputs only (PDF/DOCX/email/Slack), never DOM
export function rtlLine(s: string): string                           // RLM prefix if first strong is LTR
export function stripBidiControls(s: string): string                 // U+200E/F, 202A–202E, 2066–2069, 061C, 2060
export function hebrewList(items: string[], locale: "he"|"en", type?: "conjunction"|"disjunction"): string
```
`fixHebrewTypography` rules, applied in order:
1. Tokenize and protect URLs, emails, `@mentions`, `` `code` `` spans and existing control characters.
2. **RLM after a Latin word before digits.** A Latin token (`[A-Za-z][A-Za-z0-9.+#&'’-]*`) followed by whitespace and then a digit, in a string with Hebrew or an RTL base, gets `RLM` after the token. Example: "פגישה עם Lisboa 12 משתתפים" no longer renders as "12 Lisboa".
3. **Word-joiner after prefix hyphens.** `(^|[\s(\["'׳״])([ובכלמשה]{1,3})([-־])(?=[A-Za-z0-9])` gets `WJ` after the hyphen, so "ל-Google" and "ב-14:30" never break.
4. **No-break space before a dash.** `" — "` and `" – "` become `NBSP + dash + " "`.
5. Never insert a control character next to an existing one. Running it twice equals running it once.

`hebrewList`: if the last item starts with a non-Hebrew character, the conjunction becomes "ו-"+WJ ("Slack, Notion ו-HubSpot"); otherwise Intl.ListFormat output ("א, ב וג").

## Formatting (`lib/i18n/format.ts`, A; Step 0 provides a minimal implementation)
```ts
type Fmt = { locale: "he"|"en"; timeZone: string }
formatDate(v, fmt, style: "date"|"dateShort"|"dateTime"|"time"|"weekdayDate"|"monthYear")
formatRelative(v, now: Date, fmt)     // he: "עכשיו", "לפני דקה", "לפני 5 דקות", "לפני שעתיים", "אתמול ב־14:30", "יום שלישי ב־09:00" (<7d), else "13 באוק׳ 2026"
formatDuration(ms, fmt, style: "long"|"short"|"clock")  // he long with dual forms: דקה / שתי דקות / 5 דקות; שעה / שעתיים / 3 שעות; "שעה ו־20 דקות"; en "1 hr 20 min"; clock "1:02:03"
formatNumber(n, fmt, opts?) ; formatPercent(r, fmt) ; formatCount(n, fmt, forms: {one, two?, other})   // Intl.PluralRules("he") one/two/other
formatTimecode(ms)                     // "12:34" / "1:02:03", Western digits
```
- The dictionary gets plural support: `t.plural("meetingsCount", n)` looks up `<key>_one|_two|_other` and falls back to `_other`.
- `formatMessage` keeps `{name}` placeholders.

## Risks and defaults (flag in the PR)
- **Dropping pt/es/it** is user-visible. They were mostly untranslated; restoring one means a complete module plus the parity test.
- **IBM Plex npm TTF paths** must be verified in Step 0. If they are wrong, vendor the files into `assets/fonts/` with OFL. Glyphs outside Hebrew, Latin and Mono (Arabic, CJK, emoji) show as U+25A1 in PDFs; a Noto fallback is deferred.
- **pdfkit and tagged PDF:** tagging is basic (not full PDF/UA). Acrobat RTL selection order is checked manually.
- **Background Sync is Chromium-only.** Elsewhere the queue flushes on page load, `online` and focus. iOS Safari may evict IndexedDB data after 7 days without use; the UI warns when `persist()` is denied.
- **Screenshots in git** add about 10–15 MB. Option: Git LFS, or keep only the latest set.
- **Relative times** render absolute on the server and switch after mount, which is a deliberate hydration-safe flicker.
- **Out of scope:** notification email or push, a Hebrew-calendar date option, Arabic UI, and translating M8 provider-side content.
